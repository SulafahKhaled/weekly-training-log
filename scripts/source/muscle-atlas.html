Where the 3D model comes from

Anatomy data: BodyParts3D / Anatomography, © The Database Center for Life Science (DBCLS), Japan — licensed CC BY 4.0. Packaged as a ready-to-render open data pack by the Somakine project (@somakine/bodyparts3d-musculoskeletal, CC BY 4.0).

Renderer: the open-source Somakine viewer (@somakine/viewer + @somakine/core, MIT) built on Three.js (MIT, mrdoob & contributors).

Of the 45 real muscle meshes shown, a few muscles used in this plan have no separate mesh in this open dataset (latissimus dorsi, rectus abdominis, transverse abdominis, quadratus lumborum, tensor fasciae latae). Those are flagged proxy / note in their panel and shown via the nearest real, anatomically adjacent muscle instead of an invented mesh — see each panel's note for exactly what's real vs. approximate.
